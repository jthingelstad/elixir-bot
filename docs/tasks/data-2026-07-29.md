# Data brief — 2026-07-29

## Chaos Mega Draft League is detectable, not yet measurable

`player.progress.ChaosMegaDraftLeague` is now present in the live Clash Royale
player payloads. The API sentinel first recorded the key on 2026-07-20 and it
remained in every current roster capture reviewed on 2026-07-29.

| Evidence | Result |
| --- | --- |
| Current members with the field | 45 / 45 |
| Latest capture window | 2026-07-29T07:27:51Z–2026-07-29T19:15:08Z |
| Arena value | `Casual` for all 45 |
| Positive `trophies` / `bestTrophies` | 0 / 45; 0 / 45 |
| Game-mode capability side-mode entries | 0 (`progress_tracked=false`) |

The raw API data is retained in `raw_api_payloads`, but the operational
projection (`player_current_state`) has no progress field. Consequently,
`get_clan_game_modes` cannot expose this side-mode context; its current
sources are `battle_events`, `player_current_state`, and
`game_mode_contexts`.

This is a rollout baseline rather than evidence that members are playing the
mode. The product watch condition is the first non-zero `trophies` or
`bestTrophies` value. At that point, Product can decide whether a side-mode
view or participation signal would improve the clan experience. Until then,
Elixir should not claim activity from field presence alone.
